# ميزان

تطبيق مالي شخصي لمستخدم واحد، عربي RTL بالكامل، بالريال السعودي. الرئيسية فيها كل شي تقريباً: رقم «تقدر تصرف اليوم»، توقع نهاية الدورة، المدفوعات القادمة، وكل شي ثاني يفتح كورقة سفلية.

> هذي **المرحلة ١** من ٦. الموجود الآن: الدخول بالبريد، الرئيسية، الإدخال اليدوي، الالتزامات الثابتة، والإعدادات.
> قادم: الميزان والفائض/العجز (٢)، رسائل البنك والاختصار (٣)، البحث والإدخال السريع (٤)، الأقساط والمتكرر والتنبيهات والأهداف (٥)، تصوير الفواتير والتلميع (٦).

## كيف يحسب «تقدر تصرف اليوم»

1. الراتب − الالتزامات الثابتة في الدورة = ميزانية المصروف (أو تحدد ميزانية بنفسك).
2. (الميزانية − صرفك قبل اليوم) ÷ الأيام الباقية (مع اليوم) = حصة اليوم.
3. حصة اليوم − صرفك اليوم = الرقم الكبير. يصير أحمر لو تعديت.

الدورة تبدأ يوم ٢٧ (تتغير من الإعدادات)، وإذا صادف ٢٧ جمعة ينزل الراتب الخميس، وإذا صادف سبت ينزل الأحد.
التوقع: لو مضى على الدورة ٣ أيام أو أكثر يستخدم معدل صرفك الفعلي، وقبلها يستخدم مخصصك اليومي.

## التشغيل على جهازك

```bash
cd app
npm install
cp .env.example .env.local     # عبّي المفتاحين من Supabase (الخطوات تحت)
npm run dev                    # http://localhost:3000
```

**تجربة بدون Supabase:** شغّل بالوضع التجريبي، البيانات تنحفظ في المتصفح فقط وفيها أمثلة جاهزة:

```bash
NEXT_PUBLIC_DEMO=1 npm run dev
```

لا تضع هذا المتغير أبداً في النشر الفعلي.

## ربط Supabase (مجاني)

1. سجّل في supabase.com وأنشئ مشروعاً جديداً. اختر أقرب منطقة، وسجّل كلمة سر قاعدة البيانات في مكان آمن.
2. **قاعدة البيانات:** افتح SQL Editor والصق محتوى `supabase/migrations/0001_init.sql` ثم Run. أي مرحلة قادمة تجي بملف جديد بنفس الطريقة (ما تمسح بياناتك).
3. **المفاتيح:** Project Settings ← API. انسخ `Project URL` و`anon public key` إلى `.env.local`.
4. **كود الدخول:** Authentication ← Emails ← قالب Magic Link، وبدّل محتواه ليعرض الكود:
   ```html
   <h2>كود الدخول</h2>
   <p>{{ .Token }}</p>
   ```
5. بعد أول تسجيل دخول ناجح: Authentication ← Sign In / Providers ← عطّل **Allow new users to sign up**. بكذا محد غيرك يقدر يسجل، والبيانات محمية بعد ذلك بسياسات RLS على مستوى الصفوف.

## النشر على Vercel (مجاني)

1. ارفع المشروع إلى GitHub (أو استخدم المستودع الحالي)، وفي Vercel اختر Import Project.
2. **Root Directory = `app`**. هذا مهم لأن المستودع فيه تطبيق «مالي» القديم بجذره.
3. أضف متغيرات البيئة `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`، ثم Deploy.
4. في Supabase: Authentication ← URL Configuration، حط رابط Vercel في Site URL.

## تثبيته على الآيفون

افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية». يفتح بدون شريط المتصفح.

## الهيكل

- `lib/cycle.ts` و`lib/budget.ts` و`lib/money.ts`: كل الحسابات، بدون واجهة، ومغطاة بالاختبارات. المبالغ أعداد صحيحة بالهللات.
- `lib/repo*.ts`: طبقة البيانات (Supabase، أو تجريبي في المتصفح).
- `supabase/migrations/`: تغييرات قاعدة البيانات مرقّمة وبالإضافة فقط.
- `components/`: الواجهة. الرئيسية في `Home.tsx` والأوراق السفلية بقية الملفات.
