# ميزان

تطبيق مالي شخصي لمستخدم واحد، عربي RTL بالكامل، بالريال السعودي. الرئيسية فيها كل شي تقريباً، وكل شي ثاني يفتح كورقة سفلية فوقها بدل صفحات جديدة. بدون ذكاء اصطناعي: كل الذكاء حسابات وقواعد على بياناتك الفعلية، فما فيه تخمين.

## وش يسوي

| | |
|---|---|
| **الرئيسية** | رقم كبير «تقدر تصرف اليوم»، توقع نهاية الدورة، الميزان التراكمي، المدفوعات القادمة (تفتح وتقفل)، آخر العمليات. التنبيهات تطلع لحالها بس لما يكون فيه شي مهم. |
| **الدورة** | تبدأ يوم ٢٧ (تتغير). إذا صادف الجمعة ينزل الراتب الخميس، وإذا صادف السبت ينزل الأحد. |
| **البنود والفائض/العجز** | قسّم راتبك لبنود (مصاريف، استثمار، طوارئ، أو أي بند تضيفه). كل بند له فائضه المتراكم من دورة لدورة. العجز يتغطى من فائض نفس البند. الفائض ما ينتقل لبند ثاني ولا ينضاف تلقائياً لاستثمار أو طوارئ. الأخضر فائض والأحمر عجز. |
| **رسائل البنك** | اختصار الآيفون يرسل الرسالة، والتطبيق يستخرج المبلغ والتاجر والبطاقة والتاريخ والنوع. يدعم الراجحي، الأهلي، الإنماء، STC Bank، D360، تابي، تمارا. |
| **يتعلم منك** | تصحح تصنيف تاجر مرة، ويطبّقه بعدين بدون ما يسأل. |
| **إدخال سريع** | اكتب أو أملِ بميكروفون الكيبورد: «قهوة 18»، «بنزين 90 أمس»، «استرداد 50 نون». |
| **اسأل ميزان** | بالعامية: «كم صرفت على المطاعم؟»، «أقدر أشتري شي بـ 800؟»، «وش أكثر شي يستهلك فلوسي؟». يجاوب من أرقامك، ويقول بصراحة إذا ما فهم. |
| **تصوير الإيصال** | يقرأ الإجمالي والمحل والتاريخ داخل جوالك، والصورة ما تفارقه. |
| **الأقساط** | تابي وتمارا وأي تقسيط: كم دفعت وكم باقي وتواريخها. تدخل «المدفوعات القادمة» وتنخصم من ميزانيتك. |
| **المتكرر** | يكتشف الاشتراكات (شهرية وأسبوعية) وينبهك لو ارتفع سعرها أو ما انسحبت. |
| **التنبيهات** | عملية غير معتادة، عملية مكررة، اقتراب من حد بند، دفعة متأخرة، وملخص أسبوعي الخميس والجمعة. |
| **الأهداف** | يحسب متى توصل بمعدلك، ووش تغيّر عشان توصل أسرع. |
| **نسخ احتياطي** | تصدير JSON وExcel، واسترجاع من JSON بدون ما يحذف شي. |
| **PWA** | يتثبت على شاشة الآيفون ويفتح كتطبيق، ويفتح بدون إنترنت (البيانات تحتاج اتصال). |

## كيف يحسب «تقدر تصرف اليوم»

1. ميزانية المصروف = مجموع البنود اللي تدخل في المسموح اليوم. (لو ما عرّفت بنود: الراتب − الالتزامات الثابتة، أو ميزانية تحددها بنفسك.)
2. (الميزانية − صرفك قبل اليوم) ÷ الأيام الباقية مع اليوم = حصة اليوم.
3. حصة اليوم − صرفك اليوم = الرقم الكبير. يصير أحمر لو تعدّيت.

المصروف على بنود ثانية (استثمار، طوارئ) ما ينقص هذا الرقم، وينقص فائض بندهم.
التوقع: بعد ٣ أيام من الدورة يستخدم معدل صرفك الفعلي، وقبلها يستخدم مخصصك اليومي.

## التشغيل على جهازك

```bash
cd app
npm install
cp .env.example .env.local        # عبّي المفتاحين (الخطوات تحت)
npm run dev                       # http://localhost:3000
```

**تجربة بدون Supabase** (البيانات تنحفظ في المتصفح فقط، وفيها أمثلة جاهزة):

```bash
NEXT_PUBLIC_DEMO=1 npm run dev
```

لا تضع `NEXT_PUBLIC_DEMO` أبداً في النشر الفعلي.

## الإعداد الأول (مرة وحدة)

### ١. Supabase (قاعدة البيانات والدخول)

1. سجّل في supabase.com وأنشئ مشروعاً (الباقة المجانية).
2. **SQL Editor** ← New query ← الصق كل محتوى `supabase/setup.sql` ← Run. هذا ينشئ الجداول وأمان الصفوف (RLS). لازم يطلع `Success`.
3. **Authentication ← Sign In / Providers ← Email**: عطّل **Confirm email**.
4. **Project Settings ← API Keys**: انسخ `Project URL` و**Publishable key** (يبدأ بـ `sb_publishable_`، أو `anon` القديم). **لا تستخدم** مفتاح `secret` أو `service_role` في أي مكان.
5. افتح التطبيق، اضغط «أول مرة؟ أنشئ حسابك»، واكتب بريدك وكلمة سر قوية.
6. **مباشرة بعدها**: Authentication ← Sign In / Providers ← عطّل **Allow new users to sign up**. بكذا محد غيرك يقدر يسجّل.

### ٢. النشر على Vercel (مجاني)

1. vercel.com ← Add New ← Project ← اختر المستودع.
2. **Root Directory = `app`** (المستودع فيه تطبيق «مالي» القديم بالجذر).
3. **Branch** = الفرع اللي فيه هذا التطبيق (`new-app`).
4. Environment Variables:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` (الـ Publishable key)
5. Deploy.

### ٣. تثبيته على الآيفون

افتح الرابط في **Safari** ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## ربط رسائل البنك (اختصار الآيفون)

1. في التطبيق: ⚙️ الإعدادات ← **📩 رسائل البنك** ← **ربط الاختصار** ← **أنشئ مفتاح الربط**. انسخ المفتاح (يظهر مرة وحدة، ويُحفظ منه بصمته فقط) وانسخ «رابط الاستقبال».
2. تطبيق **الاختصارات** (Shortcuts) ← **الأتمتة** (Automation) ← **＋** ← **رسالة** (Message).
3. **المرسل**: اختر جهات البنك اللي تجيك منها الرسائل. أو «الرسالة تحتوي» واكتب `SAR`. تقدر تسوي أتمتة لكل بنك.
4. اختر **تشغيل فوري** (Run Immediately) وعطّل **إشعار عند التشغيل**. ثم التالي.
5. **أتمتة جديدة فارغة** ← **إضافة إجراء** ← **الحصول على محتويات عنوان URL** (Get Contents of URL).
6. الصق **رابط الاستقبال** في URL، واضغط السهم لإظهار الخيارات:
   - **الطريقة**: `POST`
   - **الرؤوس**: `Authorization` = `Bearer ` ثم المفتاح (مسافة وحدة بعد كلمة Bearer)
   - **نص الطلب**: JSON، وأضف حقل نص اسمه `text` وقيمته المتغير **مدخل الاختصار** (Shortcut Input). اختياري: حقل `sender` وقيمته **المرسل**.
7. تم. أول رسالة تصلك تظهر في «رسائل البنك».

**كيف يتصرف مع الرسائل:**

- شراء أو سحب أو استرداد ← يُسجَّل فوراً (فأرقامك تبقى صحيحة). التاجر اللي علّمته تصنيفه ينسجّل تلقائياً. التاجر الجديد ينسجّل مع تصنيف مقترح ويظهر لك للتأكيد.
- إيداع أو حوالة واردة ← تُتجاهل (مو مصروف).
- حوالة صادرة أو دفعة تقسيط ← **ما تُسجَّل لحالها**، تنتظر قرارك. رسالة تابي/تمارا تربطها بدفعة القسط بضغطة.
- نفس الرسالة مرتين خلال ١٠ دقايق ← تُعتبر تكرار.
- رموز التحقق والعروض (بدون مبلغ) ← تُرمى ولا تُخزَّن.

لو أي رسالة ما اشتغلت: الصقها يدوياً في خانة التجربة داخل «رسائل البنك». بكذا تعرف هل المشكلة في الاختصار أو في قراءة الرسالة.

## اللي لازم تعرفه (بصراحة)

- **الباقة المجانية في Supabase ما فيها نسخ احتياطي تلقائي**، وتتوقف المشاريع الخاملة بعد أسبوع بدون نشاط (استخدامك اليومي يمنع هذا). خذ نسخة من ⚙️ ← 💾 نسخ احتياطي مرة بالشهر. التطبيق يذكّرك لو مرّ أكثر من ٣٠ يوم.
- **صيغ الرسائل**: كتبت المحلل على صيغ البنوك الشائعة، لكن **ما جرّبته على رسائل حقيقية من حسابك**. أي رسالة ما يفهمها بثقة تروح لصندوق المراجعة ولا تُسجَّل غلط. أرسل لي نماذج حقيقية (بدون أرقام حساسة) وأضيفها للاختبارات.
- **الاختصار**: الخطوات مكتوبة حسب iOS الحديث، وأسماء الخيارات تختلف شوي بين الإصدارات. ما اختبرته على جهاز فعلي.
- **قراءة الإيصالات**: تشتغل داخل الجوال بدون إنترنت خارجي. دقتها تعتمد على وضوح الصورة. الإيصال الإنجليزي ممتاز، والعربي جيد لكن سطر الإجمالي الكبير والعريض قد يُقرأ غلط، وعندها أحسبه من المجموع + الضريبة أو أعرض لك الأرقام تختار. **دايماً راجع المبلغ قبل الحفظ.**
- **بدون إنترنت**: الواجهة تفتح، لكن البيانات تحتاج اتصال، فتشوف رسالة «حاول مرة ثانية».
- **التنبيهات المخفية** تُحفظ على الجهاز نفسه (ما تتزامن بين جوالك وكمبيوترك).

## الاختبارات

```bash
npm test            # ٢١٨ اختبار: حسابات الدورة والميزان والفائض والعجز، المحللات، المساعد، التصدير، وقاعدة البيانات
npm run lint
npm run build       # يفحص الأنواع أيضاً
```

اختبارات المتصفح تحتاج بناء تجريبي وPlaywright (تثبيته مرة وحدة: `npx playwright install chromium`):

```bash
NEXT_PUBLIC_DEMO=1 npm run build && NEXT_PUBLIC_DEMO=1 npx next start -p 3111
# في نافذة ثانية:
for t in smoke balance inbox quick phase5 receipt a11y pwa; do node tests/e2e/$t.mjs; done
```

اختبارات قاعدة البيانات تشغّل ملفات `supabase/migrations/` الفعلية على Postgres محلي (PGlite) وتتأكد من عزل المستخدمين والقيود. اختبار `a11y` يفحص كل الشاشات بالوضعين بـ axe، وTab ما يهرب من الورقة.

## بياناتك وتحديثات التطبيق

- كل تغيير على قاعدة البيانات ملف جديد في `supabase/migrations/` بالإضافة فقط: ما يمسح ولا يعيد كتابة بياناتك. بعد إضافة ملف شغّل `npm run bundle-sql` (واختبار يتأكد إن `setup.sql` ما تأخر).
- لتحديث مشروع شغّال: الصق **الملف الجديد فقط** في SQL Editor.
- الخطة المخططة لكل بند تُحفظ بتاريخ بدايتها، فتعديلها ما يغيّر فائض دورات سكّرت.
- المبالغ تتخزن كأعداد صحيحة بالهللات، فما فيه أخطاء كسور.

## الهيكل

- `lib/`: الحسابات بدون واجهة، مغطاة بالاختبارات
  - `cycle.ts`، `budget.ts`، `balance.ts`: الدورة، المسموح اليوم، الفائض والعجز
  - `sms/`: محلل الرسائل والتصنيف والقرار
  - `quick.ts`، `assistant.ts`: الإدخال السريع والمساعد
  - `recurring.ts`، `alerts.ts`، `goals.ts`، `installments.ts`، `receipt.ts`، `ocr.ts`، `export.ts`
  - `repo*.ts`: طبقة البيانات (Supabase، أو تجريبي في المتصفح)
- `supabase/migrations/`: تغييرات قاعدة البيانات، و`setup.sql` نسخة مجمّعة منها
- `app/api/ingest/`: استقبال رسائل البنك
- `components/`: الواجهة. الرئيسية `Home.tsx`، وكل شي ثاني ورقة سفلية
- `scripts/copy-ocr.mjs`: ينسخ محرك القراءة واللغات العربية والإنجليزية إلى `public/tesseract` وقت البناء
