# مالي V9 — لوحتك المالية

صفحة واحدة مختصرة تعرض وضعك المالي لدورة الراتب، والتفاصيل في أقسام تنفتح بضغطة.

## التثبيت على الآيفون
افتح رابط الموقع في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## وش فيها
- **مؤشر الوضع (0–100):** مريح / متوسط / ضغط، مع سبب كل درجة (نسبة الادخار، أقساط الديون من الدخل، الالتزام بالميزانية، صندوق الطوارئ). العجز يخلي الوضع «ضغط» مباشرة.
- **الأقسام:** الدخل، المصاريف الشهرية الثابتة، الديون المؤقتة، الديون الثابتة، الأهداف، المصاريف المتغيرة، التوزيع حسب البنك، الأشهر القادمة.
- **المخطط مقابل الفعلي:** لكل بند. أقل من الميزانية = أخضر (توفير)، أكثر = أحمر (تجاوز) مع تنبيه.
- **تعديل المخطط لشهر واحد** أو للبند دائمًا.
- **البنوك:** يوربي، فيجن، الراجحي، STC Bank، الجزيرة، سداد/تحويل، الأهلي، إحسان، إمكان، تابي، تمارا، البلاد، موبايلي باي، أو أي جهة أخرى.
- **المظهر:** 6 ثيمات + لون مخصص، تلقائي/نهاري/ليلي، وزر 👁 لإخفاء المبالغ.
- **نسخ احتياطي:** تصدير/استيراد JSON من الإعدادات.

## البيانات
محفوظة على جهازك فقط (`localStorage`، المفتاح `mali-v9`). أول فتح ينقل بيانات النسخة السابقة (`mali-v4`) تلقائيًا بدون حذفها، والنسخة السابقة باقية على `/old.html` (ملفاتها القديمة في الجذر كما هي).

## الملفات
- `mali9-core.js` — الحسابات وتقييم الوضع (بدون واجهة)
- `mali9.js` و `mali9.css` و `index.html` — الواجهة
- `sw9.js` — العمل بدون إنترنت
- `old.html` + بقية الملفات القديمة — النسخة السابقة
- `tests/core.test.cjs` — اختبارات: `node tests/core.test.cjs`
