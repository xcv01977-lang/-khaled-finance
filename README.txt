مالي — الإصدار 7.1.0

التشغيل والنشر:
1. فك الضغط، وارفع محتويات الحزمة إلى جذر المستودع، بما فيها index.html وapp.js وstyles.css.
2. يمكن نشرها عبر GitHub Pages أو Vercel كموقع ثابت. لا تحتاج npm أو خطوة Build.
3. للاختبار المحلي: python3 -m http.server 8080 ثم افتح http://localhost:8080.
4. على الآيفون: افتح رابط HTTPS في Safari ثم مشاركة ← إضافة للشاشة الرئيسية.
5. قبل تحديث الرابط الحالي صدّر بياناتك من الإعدادات. عند استخدام نفس الأصل يحتفظ التطبيق بمفتاح بيانات mali-v4 السابق. اختلاف الدومين أو المتصفح يتطلب استيراد النسخة.

البيانات:
السداد يدوي. لا يُضاف الراتب تلقائيًا. الفترة تبدأ في يوم الراتب وتنتهي قبل يوم الراتب التالي. صافي المسجل ليس رصيد البنك. الخزائن تعرض رصيد البداية والتحويلات حتى نهاية الفترة المختارة.
قبل آخر تغيير يحتفظ التطبيق بنسخة تراجع واحدة. هذه ليست بديلًا عن التصدير الدوري.
البيانات على المتصفح الحالي فقط، ولا توجد مزامنة بين الأجهزة أو تسجيل دخول.
الحزمة ونسخ JSON تحتوي بيانات مالية شخصية. نشر مستودع عام سيجعل بيانات البداية الموجودة في app.js متاحة للعامة؛ استخدم مستودعًا خاصًا إذا أردت إبقاء المصدر خاصًا، واعلم أن ملفات الموقع المنشور يمكن الوصول إليها بحسب إعدادات النشر.
